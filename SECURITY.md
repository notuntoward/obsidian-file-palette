# Security Policy

## Reporting a Vulnerability

This project takes security seriously. If you believe you have found a security
vulnerability, please report it privately before opening a public issue.

### How to report

* GitHub Advisories: Use the private vulnerability reporting feature at
  <https://github.com/notuntoward/file-palette/security/advisories/new>

Please include:

* A description of the vulnerability
* Steps to reproduce it
* The plugin version and Obsidian version you are using

### What to expect

* An acknowledgment within 7 days
* A fix or mitigation plan within 30 days for confirmed vulnerabilities
* Public disclosure only after a fix is available
